## 1.分包配置
小程序项目划分为多个子包，用户在使用时按需加载相应的包，从而减少首次启动时需要下载的数据量，加快启动速度。
pages.json里面配置subPackages
```json
"subPackages": [
	{
		"root": "sysManage",
		"pages": [{
			"path": "userManage/index",
			"style": {
				"navigationBarTitleText": "用户管理"
			}
		},
		{
			"path": "roleManage/index",
			"style": {
				"navigationBarTitleText": "角色管理"
			}
		}]
	},
],
```
## 2.页面之间传参数

<p>传参数：跳转路由时把参数追加到url后面</p>
<p>接受参数：</p>
方法1：

```javascript
onLoad(options) {
	// options就是url后面的参数
	console.log(options)
}
```

方法2：

```javascript
export const getRouteParams = () => {
  const pages = getCurrentPages()
  const page = pages[pages.length - 1]
  return page.options
}
```
